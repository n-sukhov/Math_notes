# Шаблон математического конспекта

Проект разделён на четыре части:

- `main.tex` — минимальный файл, который собирает документ;
- `preamble.tex` — шрифты, языки, оформление и пользовательские команды;
- `content.tex` — титульная страница и сам конспект;
- `chapters/` — отдельные файлы глав с параграфами;
- `images/` — рисунки, графики и схемы.
- `build/` — автоматически создаваемые служебные файлы компиляции.

Шаблон нужно собирать с помощью **XeLaTeX** или **LuaLaTeX**. pdfLaTeX не
подходит, поскольку проект использует Unicode-шрифты и русский текст напрямую.

## Компиляция

Из корня проекта выполните готовый сценарий сборки:

```powershell
Set-Location ".\proj_name"
.\build.ps1
```

Сценарий сам дважды запускает XeLaTeX для корректного оглавления и ссылок.
Файлы `.aux`, `.log`, `.toc`, `.out`
и другие технические файлы будут находиться в `proj_name/build/`.

Для LaTeX Workshop уже добавлен рецепт
`XeLaTeX: notes with clean build directory`. Поэтому кнопка сборки в VS Code
запускает тот же сценарий и также складывает служебные файлы в `build/`.

Эквивалентная ручная команда выглядит так (её также нужно выполнить дважды):

```powershell
xelatex --enable-installer --aux-directory=build -interaction=nonstopmode -file-line-error main.tex
```

Проверить установку можно командами:

```powershell
xelatex --version
miktex packages info polyglossia
```

## Как работать с шаблоном

1. В `preamble.tex` измените `\coursename`, `\notestitle`, `\studentname` и
   `\yearname`.
2. В `chapters/chapter-01.tex` замените демонстрационный материал своим.
   Новые главы создавайте как `chapter-02.tex`, `chapter-03.tex` и подключайте
   командами `\input` в конце `content.tex`.
3. Картинки складывайте в `images/`. Указывать `images/` в каждой команде
   `\includegraphics` не нужно.

Текст организован по схеме «глава → параграф»:

```tex
\chapter{Пределы и непрерывность}

\lecture{Предел последовательности}
Текст первого параграфа.

\lecture{Предел функции}
Текст второго параграфа.
```

В колонтитуле слева автоматически указывается текущая глава, а справа — номер и
название текущего параграфа.

Пример вставки картинки:

```tex
\begin{figure}[ht]
  \centering
  \includegraphics[width=0.75\textwidth]{graph.png}
  \caption{График функции}
  \label{fig:graph}
\end{figure}
```

## Основные конструкции

```tex
\lecture{Название параграфа}

\begin{definition}{Название}{short-label}
  Текст определения.
\end{definition}

\begin{theorem}{Название}{short-label}
  Формулировка теоремы.
\end{theorem}

\begin{axiom}{Название}{short-label}
  Формулировка аксиомы.
\end{axiom}

\begin{proof}
  Доказательство.
\end{proof}

\begin{example}{Название}{short-label}
  Пример.
\end{example}
```

Также доступны `axiom`, `lemma`, `proposition`, `remark` и `important`.

Теоремы и леммы выделяются тонкой тёмно-синей рамкой. Определения, доказательства,
аксиомы, следствия, свойства, утверждения, примеры и замечания выводятся без рамок и
цветного фона.

```tex
\begin{lemma}{Название леммы}{lemma-label}
  Формулировка леммы.
\end{lemma}

\begin{proposition}{Название утверждения}{proposition-label}
  Формулировка утверждения.
\end{proposition}

\begin{corollary}{Название следствия}{corollary-label}
  Формулировка следствия.
\end{corollary}

\begin{properties}{Название группы свойств}{properties-label}
  \begin{enumerate}
    \item Первое свойство.
    \item Второе свойство.
  \end{enumerate}
\end{properties}
```

## Правило наполнения справочника по книге

При переносе следующих глав сохраняются порядок и формулировки всех отдельно
выделенных аксиом, определений, теорем, лемм, утверждений, следствий и свойств. В
справочник не переносятся доказательства и упражнения. Нумерация формул и
смысловых блоков ведётся автоматически внутри конспекта.

Полезные математические команды: `\N`, `\Z`, `\Q`, `\R`, `\CC`, `\eps`,
`\dd`, `\diff{f}{x}`, `\pdiff{f}{x}`, `\abs{x}`, `\norm{x}`,
`\inner{x}{y}` и `\set{x}`.
